# 设施设备移动端

面向项目组织内巡检、维保人员和负责人。员工在授权项目内找任务、接单、逐项检查拍照、提交；负责人审批并可退回整改，具有派单权限的人可转单。同一任务配置同一时隙整项接单，逐设备保存结果、拍照和提交，全部设备提交后整项审批；不采用双工单或外协流程。

支持项目切换、工单池、我的任务、巡检/维保筛选、任务时间筛选、扫码设备/设备组、离线模式、草稿、照片及同步冲突保留。消息独立展示新任务、预警及超期通知。身份、项目成员、权限、版本和状态以服务端校验为准。

## 本次方向与验收

采用用户确认的天蓝色、简洁清爽方向，参考报事员工端的导航及收费业主端的安全区布局。工作台 → 紧凑任务列表 → 独立执行页；手机常用宽度320–480，桌面居中。左右留白16px，避免巨大卡片、解释性小字和后台表格。

首屏：项目选择 / 扫码；我的待办与审批入口；巡检、维保和工单池；近期任务；底部工作台、任务、同步、我的。列表筛选在列表内，整项详情显示设备清单与进度，点击设备先查看只读详情、检查要求和已提交结果；扫描匹配设备码后才可填写、拍照、保存及提交。设备组扫码图标位于提交进度旁，设备扫码图标位于设备状态旁。扫设备组码后进入该组设备清单，依次完成组内设备；扫设备码仅进入对应设备检查。任务扫码不提供手动输入，二维码类型、应用、任务快照和指定设备须匹配；刷新后重新扫码。处理记录集中在整项任务详情，单设备页不展示；所有任务页移除额外返回清单条，使用顶部返回。旧单设备任务也遵循扫码执行入口。转单与退回理由使用聚焦抽屉，不将全部流程塞进弹窗。

方案档案：处置工作台 + 筛选摘要列表 + 独立详情工作区。核心组件为已有独立H5依赖的Ant Design Vue、路由和Ant图标；不引入依赖宿主注册的PC JetLinks组件。编辑梯度为检查项原位填写、筛选抽屉、独立执行页；状态标签先于字段；每屏一个主动作区；无侧栏。未采用PC表格、嵌套大卡片、外协双工单或营销插图。用户已确认方向，按授权直接实施。

设计契约：作业优先；真实项目与任务；天空蓝强调操作；白色紧凑分区；首屏任务可达；状态、空态、长文、离线、错误及小屏均需可用。统计使用后端总数，不能将第一页长度当作总量。

导航标题统一在顶部居中，不再重复显示“设施设备”或正文页面标题。项目仅单选具体项目，记住有效选择，首次默认选中首个可用项目；无项目时不请求跨项目任务或统计。快捷入口使用与统计区域等宽的白色卡片。底部为工作台、任务、同步、消息、我的；“我的”保留消息入口，任务列表不提供刷新按钮。H5固定中文，不更改PC语言偏好。

消息以蓝色新任务、橙色预警、红色超期区分，显示项目、任务、设备提交数和执行时段；支持未读筛选、单条已读和全部已读，底部消息入口显示未读红点。周期计划填写开始后经过的预警时间，至少为单次执行时长的一半且早于结束时间；提醒按整项任务、消息类型及接收人去重。点击消息进入真实任务详情，接单和扫码执行继续受原有权限约束。

离线模式：开启时分页缓存当前账号全部已接单待办、设备组与逐设备快照、检查要求和照片；缓存完整后才启用。开启期间使用本机数据，断网可扫码、拍照、保存和提交，联网后也须在同步中心手动上传。同步保留稳定提交编号，失败或冲突保留本机结果。关闭前确认并列出未同步记录与草稿数量，确认后清空当前账号业务缓存；取消则保留。登录身份和应用静态资源不随业务缓存删除。
